# 用户模型专属倍率功能

## 功能概述

用户模型专属倍率功能允许管理员为特定用户针对不同模型设置个性化的价格倍率，实现精细化的价格控制。

## 功能特性

### ✨ 核心功能
- **个性化定价**：为不同用户对不同模型设置专属倍率
- **优先级控制**：用户-模型专属倍率 > 分组专属倍率 > 普通分组倍率
- **批量管理**：支持批量设置、导入导出功能
- **实时生效**：配置后立即生效，无需重启服务
- **缓存优化**：内置缓存机制，确保高性能

### 🎯 适用场景
- **VIP用户优惠**：为VIP用户提供特定模型的折扣价格
- **企业客户定价**：为企业客户提供批量采购优惠
- **测试用户体验**：为测试用户提供新模型的体验价格
- **个性化营销**：根据用户行为提供差异化定价

## 使用方法

### 1. 管理员配置

#### 访问管理界面
1. 登录管理员账号
2. 进入 **设置** → **倍率设置** → **用户模型倍率**

#### 新增用户模型倍率
1. 点击 **新增** 按钮
2. 填写以下信息：
   - **用户ID**：目标用户的ID
   - **模型名称**：选择要设置的模型
   - **倍率**：设置倍率值（如0.8表示8折）
   - **备注**：可选，用于说明设置原因
3. 点击 **保存**

#### 批量设置
1. 点击 **批量设置** 按钮
2. 输入用户ID
3. 添加多个模型和对应的倍率
4. 点击 **批量保存**

#### 导入导出
- **导出**：点击导出按钮，下载JSON格式的配置文件
- **导入**：点击导入按钮，上传JSON格式的配置文件

### 2. 倍率计算优先级

系统按以下优先级计算最终倍率：

```
1. 用户-模型专属倍率（最高优先级）
2. 用户组-使用组专属倍率
3. 普通分组倍率
4. 默认倍率（1.0）
```

### 3. API接口

#### 获取用户模型倍率列表
```http
GET /api/user-model-ratio/?page=1&page_size=20&keyword=&user_id=
```

#### 设置用户模型倍率
```http
POST /api/user-model-ratio/
Content-Type: application/json

{
  "user_id": 123,
  "model_name": "gpt-4",
  "ratio": 0.8,
  "remark": "VIP用户8折优惠"
}
```

#### 批量设置用户模型倍率
```http
POST /api/user-model-ratio/batch
Content-Type: application/json

{
  "user_id": 123,
  "model_ratios": {
    "gpt-4": 0.8,
    "claude-3": 0.9
  }
}
```

#### 删除用户模型倍率
```http
DELETE /api/user-model-ratio/{user_id}/{model_name}
```

#### 获取用户模型倍率映射
```http
GET /api/user-model-ratio/{user_id}
```

## 数据库结构

### user_model_ratios 表

| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | INT | 主键，自增 |
| user_id | INT | 用户ID |
| model_name | VARCHAR(255) | 模型名称 |
| ratio | DECIMAL(10,4) | 倍率值 |
| created_time | BIGINT | 创建时间 |
| updated_time | BIGINT | 更新时间 |
| remark | VARCHAR(255) | 备注 |

### 索引说明
- `uk_user_model`：user_id + model_name 唯一索引
- `idx_user_id`：user_id 索引
- `idx_model_name`：model_name 索引

## 注意事项

### ⚠️ 重要提醒
1. **倍率值范围**：倍率必须大于0.01，通常设置在0.1-2.0之间
2. **生效时间**：配置保存后立即生效，影响后续所有请求
3. **缓存机制**：系统使用5分钟缓存，确保高性能访问
4. **权限控制**：只有管理员才能配置用户模型倍率
5. **数据一致性**：删除用户时建议同时清理相关倍率配置

### 🔧 故障排除
1. **倍率不生效**：检查用户ID和模型名称是否正确
2. **性能问题**：大量配置时建议使用批量操作
3. **缓存问题**：如需立即生效，可重启服务清空缓存
